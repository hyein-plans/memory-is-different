# 기억이 달라

라이트 추리·기억 비교 웹게임 프로토타입 저장소입니다.

## 현재 작업
- #01 사라진 별사탕
- SET A 프로토타입
- 닉네임 입력
- 기억 카드 2장
- 전원 준비 후 FACT 동시 공개
- 최종 지목 및 결과 공개

## 구조
- `index.html` — 클릭형 웹 프로토타입
- `assets/hero/` — 메인 사건 삽화
- `assets/facts/` — FACT 삽화
- `assets/memory/` — 기억 카드용 오브젝트 에셋

아트 방향은 색연필·파스텔·동화책·스크랩북 질감의 따뜻한 미스터리 톤을 기준으로 합니다.
